# ImageViewer

## 用途

縮小して並べている画像を、押したときに大きく表示します。

## 役割と公開 component

| Component | 役割 |
| --- | --- |
| `ImageViewer` | 縮小版を trigger にして、拡大版を `Dialog` で開きます。 |

## 利用ケース

carousel やギャラリーのように画像を縮小して並べている場所で、細部を確かめたい場面に使います。

画像そのものが主役ではない場所（アバター、アイコン、装飾）には使いません。押せる見た目を与えても、開いた先に得るものがありません。

## 責務境界

**並べ方・枠・比率は持ちません。** trigger の中身は呼び出し元が `children` として渡します。carousel に載せるのか単独で置くのかで枠が変わり、ここで決めると置き場ごとに上書きが要るためです。

**画像が無いときの代替も持ちません。** 何を代わりに出すかは対象の性質で決まるため、呼び出し元が `MediaImage` の `fallbackSrc` などで扱います。押せる画像と押せない画像の出し分けも呼び出し元の判断です。

開閉・focus trap・Escape・背面の inert 化は `Dialog` に委ねます。

## 位置の往復

拡大版も carousel です。1 枚だけを見せると、次を見るために閉じて選び直す往復が要ります。送りは本体と同じ機構（横スクロールと吸着）に乗るため、touch のスワイプがそのまま効きます。

**開くときは押した位置から始め、閉じるときは送り終えた位置へ本体を寄せます。** 合わせないと、拡大版で 3 枚目まで送って閉じたのに本体は 1 枚目のまま、という食い違いが残ります。

本体は DOM の先祖（`[data-slot="carousel-content"]`）を辿って見つけます。carousel の外へ置いた場合は開始位置だけが効き、寄せる相手が無いので何も起きません。

閉じたあとの focus は、押した trigger ではなく**送り終えた位置の trigger**へ戻します。既定の focus 復帰に任せると、ブラウザが押した trigger の slide を画面内へ引き寄せ、寄せたばかりの位置が押し戻されます。

## 拡大版の収め方

viewport に対する箱へ `object-contain` で収めます。画像の実寸を知らずに原寸で描くと、縦長の画像が画面からはみ出して全体を見られません。切り抜かないのは、拡大が「全部を見る」ための操作だからです。

`Dialog` の既定の幅（`sm:max-w-lg`）は文章のための読み幅なので、変種ごと外して画像の幅を採ります。

## アクセシビリティ

trigger は `button` です。画像に click を付ける形は keyboard から辿れず、押せることも伝わりません。

trigger のアクセシブルな名前は「〈説明〉を拡大する」です。縮小版の代替テキストだけでは、押すと何が起きるかが操作の一覧から分かりません。

dialog のアクセシブルな名前は画像の説明そのものです。同じ画像を開いただけなので、拡大版に別の説明を与えません。

## 印刷

trigger は紙に出しません。押せない操作であり、拡大版は開いていなければ DOM にも居ません。

## Storybook とテスト

Storybook は単独で置いた縮小版、途中の 1 枚から開く場合、carousel に載せた場合を確認します。carousel に載せた story では、拡大版で送ってから閉じると背後の carousel がその位置へ寄ることを見ます。
