# CopyButton

## 用途

値を clipboard へコピーする操作です。識別子・URL・API キーのように、利用者が別の場所へ貼り付ける値へ添えます。

## 役割と公開

| Component / 値 | 役割 |
| --- | --- |
| `CopyButton` | 値を clipboard へコピーする client island です。 |
| `COPY_FEEDBACK_MS` | コピーした合図を表示し続ける時間（ミリ秒）です。 |

`Button` の props をそのまま受け取ります（`children` / `onClick` / `type` を除く）。

## 名前は必須です

`label` は必須です。アイコンだけの操作は、名前が無いと支援技術から用途が分かりません。同じ画面に複数のコピー操作が並ぶため、「識別子を写す」のように**何をコピーするのかが分かる語**にします。

コピーした直後は読み上げ専用の語を live region へ出します。マーカーが check へ変わるだけでは、画面を見ていない利用者に成否が伝わりません。

## 失敗しても止めません

clipboard は安全な文脈でしか使えず、利用者が許可しない場合もあります。失敗しても例外は投げず、合図を出さないだけにとどめます。**コピーできたことを前提にした導線を feature 側で組まないでください。**

## `capabilities` の hook にしていない理由

再利用したい実体は browser 能力ではなく「コピーして、コピーできたと伝える操作」です。`navigator.clipboard.writeText` の呼び出しは 1 行で、残りはすべて UI の決定です。

| 要素 | 種別 |
| --- | --- |
| `navigator.clipboard.writeText` | browser 能力 |
| 名前を必須にする | UI の決定 |
| コピーした語を読み上げる | UI の決定 |
| 合図を戻す時間と unmount 時の解除 | UI の状態管理 |
| 失敗しても合図を出さないだけにする | UI の方針 |

hook へ移せるのは 1 行目だけで、残りは各利用箇所へ残ります。**ボタン以外の面からコピーする必要が出た時点**（`DropdownMenu` の項目や keyboard shortcut など、`button` ではない面）で、共有する部分を `capabilities` の hook へ切り出し、この component もそれを使う形へ寄せます。

## 責務境界

コピーする文字列の整形は持ちません。表示している値とコピーされる値がずれないよう、整形済みの同じ文字列を渡します。整形は `model/` の formatter が持ちます。

コピーできたかどうかの記録、再試行、通知は持ちません。

## Storybook とテスト

Storybook はデフォルト、合図の文言を変えた場合、見た目を変えた場合、値の隣へ添えた場合を確認します。テストはアクセシブルな名前、clipboard へコピーすること、合図の表示と一定時間での消滅、文言の差し替え、clipboard が使えない場合に例外を投げないこと、a11y 自動検査を確認します。
