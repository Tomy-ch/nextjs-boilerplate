# `/mypage/coupons` クーポン（画面要件）

> 機能要件は [`page.function.md`](page.function.ja.md)。

保有クーポンを状態つきで確かめ、キャンペーンコードで新しく 1 枚受け取る画面。マイページとは独立した
ルート。

## 見せるもの

ページ見出しの下に、上から順にパンくず、受け取り欄、保有クーポンの一覧。

**受け取り欄は一覧の上に置く。** 受け取りが成立すると一覧が 1 行増える。欄を一覧の下に置くと、行が
増えるたびに欄の位置が動く。

一覧の各行が見せるもの:

| 行 | 内容 |
| --- | --- |
| 見出し | 状態のマーカー、続けて値引き（上限があればそれも） |
| 条件 | 対象（全商品 / カテゴリ / 商品）と、あれば購入額の下限 |
| 時刻 | その状態で確かめたい時刻 —— 使用済み: 使った日時 / 利用開始前: 使えるようになる日時と期限 / それ以外: 期限 |

状態は **未使用 / 使用済み / 期限切れ / 利用開始前** の 4 つ。**意味はマーカーの文字が伝え、色は補う
だけ。** 状態は券そのものの状態で、いまのカートで使えるかはここでは言わない —— それに答えるのは購入の
手続き。

行は押せない。読むための一覧。

## 受け取りの見え方

| 場面 | 表示 |
| --- | --- |
| 欄が空（または空白だけ）のまま `[受け取る]` を押した | 送らない。欄の脇にコードの入力を促す文言を出し、打ち始めたら消す。ボタンを押せなくはしないので、理由に必ず辿り着ける |
| 送信中 | ボタンが処理中であることを示す |
| 受け取れた | toast で知らせ、欄を空にし、取り直した一覧に 1 行増える |
| コードが受け付けられなかった | 欄の脇に 1 つの文言。理由によらず同じ。入力は残し、打ち直させずに直させる |
| 受け取りが競合した（`409`） / 一時的に使えない | フォームの脇に文言。コードは残し、結果が分かるまで書き換えさせず、理由を欄に紐づける |
| 要求を読めなかった | フォームの脇に文言。入力は残す |

**成功しても画面は移らない。** 受け取った証拠は一覧に現れる 1 行で、再読み込みしても消えない
（[0063](../../../../../adr/0063-mutation-result-notification.ja.md)）。

## 空の状態

1 枚も持っていないときは、一覧の場所でそう伝え、上の受け取り欄を指す。受け取り欄は残る。

## 待機

ページ見出しは残る。その下 —— パンくず、受け取り欄、一覧 —— は一覧が届くまでプレースホルダーに置き換わる。
プレースホルダーは受け取り欄の場所を確保するので、一覧が届いても欄は動かない。

## 失敗の見え方

一覧を取得できないときは、見出しの下が再試行つきの失敗表示に置き換わる。受け取り欄だけを出すことは
しない —— 一覧が無いと、受け取りの結果を確かめる場所が無い。

## 幅による組み替え

| 幅 | 受け取り欄 |
| --- | --- |
| `sm` 以上 | 入力とボタンを横に並べる |
| `sm` 未満 | 縦に積む |

一覧はどの幅でも 1 列。

## パンくず

`マイページ > クーポン` を置く。global nav から 1 手で辿れない祖先を持つ
（[0026](../../../../../adr/0026-layout-shell-mount.ja.md)）。

## カタログでの確認

一覧は fixture から来るので、4 つの状態を一度に見られる。受け取りの結果は受け取り欄の各 story の中で
差し替えている。story id は [feature README](../../../../../../src/features/coupons/README.ja.md) を参照。
