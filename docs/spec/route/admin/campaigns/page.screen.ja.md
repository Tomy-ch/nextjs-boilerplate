# `/admin/campaigns` キャンペーン一覧（画面要件）

> 機能要件は [`page.function.md`](page.function.ja.md)。
>
> レイアウトシェルの約束は [`../layout.screen.md`](../layout.screen.ja.md) が持つ。

各キャンペーンの配布がどうなっているかを見て、止める画面。

## 何を出すか

上から次の順に置く。

| 領域 | 中身 |
| --- | --- |
| 見出し | 画面の名前と、ここから何ができるか |
| 期間の注記 | 配布は開始から終了の直前までで、終了の時刻からは受け取れないこと |
| 結果 | 直前の停止の結果。送った後だけ |
| 一覧 | キャンペーンの表と、その下のページ送り |

**期間の終わりは表の上で 1 度だけ説明する。** 行ごとに書くと同じ断りが並び、書かないと終了の時刻が
受け取れる最後の瞬間に読める。

## 表に出す列

| 列 | 中身 | 出すバンド |
| --- | --- | --- |
| コード | キャンペーンコード。表を広げずに折り返す | すべてのバンド |
| 状態 | 状態の名前のバッジ | すべてのバンド |
| 配布期間 | 開始 〜 終了。どちらも時刻まで | `md` |
| 残数 | 残数 / 総数の上限 | すべてのバンド |
| 値引き | 額面。率の値引きでは下に上限を添える | `md` |
| 対象 | クーポンがどの商品に使えるか | `md` |
| クーポンの期限 | 配ったクーポンがいつ切れるか | `xl` |
| 停止日時 | いつ停止されたか。停止されていなければダッシュ | `xl` |
| 操作 | 行末の操作 menu | すべてのバンド |

**狭いバンドで残すのは「どれか」「どういう状態か」「あといくつか」「何ができるか」。** それ以外を残すと、
横送りしないと操作に届かなくなる。

**クーポンの期限と停止日時は最も広いバンドにだけ出す。** 1 件を詳しく読むための値であって、行を
見比べる手がかりではない。またサイドバーの一覧が常に出ているバンドでは表が狭すぎ、日時が折り返して
行の高さが揃わなくなる。

**期間は時刻まで出す。** 両端は瞬時なので、日付に丸めない。

**出さないもの: 1 人あたりの上限、最低購入額、クーポンが使えるようになる日時、発行済みの数そのもの、
対象の具体的な相手。**

**表が入り切らない幅では、表だけが自分の領域の中で横に送れる。** 画面そのものは横にあふれない。

## 状態は文字で示す

**各状態は名前を持つバッジで出す** —— 「配布前」「配布中」「期間外」「停止」。色は名前に重ねるだけで、
色だけで区別させない（[0100](../../../../adr/0100-accessibility-target.ja.md)）。区分とその色は
[`page.function.md`](page.function.ja.md) が持つ。

**停止済みのキャンペーンだけを明度の反転で出す。** 期間の状態とは別の軸で見分けさせる。

## 残数

**配り切ったキャンペーンは、数の下に「上限到達」の文字を失敗の色で添える。** 色は文字に重ねるだけで、
唯一の合図にはしない。

## 行の操作

**行末の操作 menu の中に「停止する」を破壊的な見た目で置く。** 不可逆な操作を、一覧の上に裸で並べない。

**停止済みの行には操作の trigger ごと出さない。** 押せる物が並んでいるのに開くと空、という面を作らない。

## 停止の確認

**背面を塞ぐ確認を出す。** 見出しはコードを名指す —— 「{code} の配布を停止しますか？」 —— そしてコードは
ダイアログを引き伸ばさずに折り返す。

**本文には、取り消せないこと、以後そのコードは受け取りを受け付けないこと、配ったクーポンは無効に
ならず引き続き使えることを書く。**

**選択肢は「やめる」と「停止する」で、後者は破壊的な見た目。** 背面を押しても閉じない。送信中は
ボタンがそう示し、もう一度押せない。

**結果が返ったら、成否によらず閉じる。** 確認は「本当に押すか」を尋ねる面であって、結果を語る面では
ない。結果は送った行に答える。送信中に確認を閉じて別の行の確認を開いていたら、そちらは開いたままにする。

## 結果は一覧の上に残す

**成立も失敗も、表の上の、一覧全体で 1 か所に出す。** 確認は閉じるのでその中には残せず、行ごとに
出すとどれが最新の結果か分からなくなる。

| 結果 | 出すもの |
| --- | --- |
| 成功 | 「{code} の配布を停止しました」と、配ったクーポンは引き続き使えること |
| 既に停止済み | 停止できなかったこと。コードを名指し、既に停止済みであることと一覧を更新したことを言う |
| 対象が送られてこなかった | 停止できなかったこと。画面を開き直すよう求める |
| その他の失敗 | 停止できなかったこと。その区分に対するカタログの文言で |

**成功の文言は、配ったクーポンが引き続き使えることを繰り返す。** 確認で読んだことが、閉じた後も同じ
言葉で残る。

**一覧をその下で取り直すあいだも結果は残る。** 停止した行はその場で「停止」に変わる。

## ページ送り

**表の下に、任意のページへ跳べるページ送りを置く。** 先頭・末尾・現在の両隣を出し、離れた範囲は省略の
マーカーで畳む。

**端では前後を消さず、押せない状態で残す。** 消すと残った側が左右へ動き、同じ場所を狙って押せない。

**入り切らない幅では折り返す。**

## 読み込み中

**見出しは残し、表は行の形をした枠に置き換える。** スピナー 1 つで代えると、中身がレンダリングされた
瞬間に高さが変わり、下に置いたページ送りが動く。

**ページが変わるときは期間の注記も残し、一覧だけが待つ。**

## 該当が無いとき

**表の形は保ったまま、まだキャンペーンが無いことだけを伝える。**

## 失敗の見え方

**一覧を取得できないときは、見出しを含めたメインコンテンツを差し替える。** レイアウトシェルは
[`../layout.screen.md`](../layout.screen.ja.md) の約束どおり残る。

## パンくず

**置かない。** サイドバーの一覧がこの画面を直接指しており、間に段がない。

## カタログでの確認

Storybook の `Page/Admin/Campaigns/List` に、すべての状態と配り切った行の混在（タブレット・スマホ付き）・
キャンペーンなし・読み込み中・取得の失敗・途中のページ・末尾のページ・1 ページしかない場合・行の操作を
開いた状態・停止の確認・成功・既に停止済み・その他の失敗・長いコードを置く。送信中は
`Features/Admin/Campaigns/List/SuspendDialog/Submitting` が持つ。
