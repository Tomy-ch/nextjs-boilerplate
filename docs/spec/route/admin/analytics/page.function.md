# `/admin/analytics` 期間別の集計（機能要件）

> 画面要件は [`page.screen.md`](page.screen.md)。
>
> 器の約束は [`../layout.function.md`](../layout.function.md) が持つ。

## 主体と所有

管理者だけが開ける。判定は器が持つ。所有者の概念は無い。

## 期間は URL が持つ

**効いている期間は URL に載る。** 共有したリンク・戻る操作・再読み込みのいずれでも同じ結果になる
必要があり、client の状態に持つとそのどれも成立しない。

| 条件 | 値 |
| --- | --- |
| 期間の区分 | `today`（既定）/ `month` / `range` |
| 開始日 | `range` のときだけ。暦日 |
| 終了日 | `range` のときだけ。暦日。この日を含む |

**キー名は契約のものを使い、送る側で読み替えない。**

**`range` 以外では日付を載せない。** 契約は無視すると宣言しているが、送らなければ「無視されるはずの
値が効いていた」という疑いがそもそも立たない。

## 条件の検証

URL から読んだ期間は、**取得の口が持つ検証**（`parseDashboardQuery`）を通してから渡す。画面側で写しを
作ると、契約を再生成しても写し方だけが古い範囲のまま残る。

写せなかった期間は捨てず、集計の代わりにそのことを出す。読めない期間を既定へ戻して今日の集計を出すと、
指定したつもりの期間とは違う数を、違うと判らないまま読むことになる。

## 期間が成立しているかは画面が見る

契約は**日付の欠けた `range`** も**前後の入れ替わった `range`** も 400 で返す。しかしどちらも
**これから日付を選ぶ状態**と同じ URL の形をしている。往復させてから拒まれる形にしないため、送る前に
画面が見る（[0062](../../../../adr/0062-form-input-validation.md)）。

| 状態 | 扱い |
| --- | --- |
| 日付が揃っていない | 集計を求めない。両方を選ぶよう促す |
| 終了日が開始日より前 | 集計を求めない。選び直すよう促す |

**日付の前後は文字列のまま比べる。** 契約が受け取る `YYYY-MM-DD` は桁が固定なので、辞書順がそのまま
暦の順になる。`Date` へ直すと、ブラウザの時差で暦日がずれた値どうしを比べることになる。

## 対象の暦日は写しである

**境界を決めているのはバックエンドで、応答には入っていない。** どの日を見ているのかを画面に出すには、
同じ規則をこちら側でも辿るしかない。写しである以上、バックエンドの設定が変われば黙ってずれる。

集計そのものはバックエンドの値をそのまま出しており、**ここでずれるのは添える文言だけ**である。恒久の
解は契約が解決済みの期間を返すこと。

**いまの時刻は URL を解釈する層が読む。** 描画のたびに実時計を読む部品にすると、基準画像が撮った時刻に
依存する。

## 取り直す範囲

取得は 2 つに分かれ、それぞれが待機と失敗の単位になる。

| 区画 | 取得 | 期間に従うか |
| --- | --- | --- |
| 集計 | `GET /v1/dashboard/summary` | 従う |
| 売れ筋 | `GET /v1/products/ranking` | **従わない** |

**URL を解釈する層は取得を持たない。** 持つと、選択肢まで含めた画面全体が待機表示に置き換わる。

**集計の待機に鍵を与える。** 期間が変われば数値が総入れ替えになる。鍵を与えないと、次の集計が届くまで
前の期間の数が残る。鍵は値を一意に表す形で作る —— 区切り文字で連結すると、値に区切り文字が現れた
時点で別の期間が同じ鍵になる。

## 売れ筋の期間が対応しない

`GET /v1/products/ranking` が受け付ける期間は全期間と直近 30 日の 2 つだけで、この画面の区分と対応
しない。**直近 30 日に固定し、そのことを見出しに書く。**

母集団も違う。ランキングは公開済みの商品に限り、明細（単価 × 数量）を集計する。`salesAmount` は購入の
総額（小計 + 税 + 送料）で、商品の公開状態を見ない。**足しても一致しない。**

## 取得の失敗

`/admin` の error 境界が受ける。境界は器の直下に 1 枚だけあり、落ちた画面の区別は届かない。

## 現契約でできないこと

**期間ごとの売れ筋が取れない。** 上記のとおり、ランキングの期間がこの画面の区分と対応しない。

**売上の金額の内訳が取れない。** ランキングは販売数量だけを返し、金額を持たない。
