# `auth` 外枠（画面要件）

> 機能要件は持ちません。この外枠が約束するのは見え方だけです。

認証の往復に関わる画面（[`/login`](login/page.screen.md) / [`/onboarding`](onboarding/page.screen.md)）を
包む器。

## 見せるもの

利用者向けの外枠とは別の器で、**ナビゲーションも脇の領域も出さない**。認証を促している最中に
他の導線を並べると、そこから離脱した利用者が元の操作へ戻れなくなる
（[0026](../../../adr/0026-layout-shell-mount.md)）。

**それでも器そのものは通す。** header の site 名から出発点へ戻れる経路を残すためで、枠ごと外すと
認証をやめたい利用者に「戻る」以外の手段が無くなる。

## パンくず

置かない。この器の中の画面に着いた利用者はまだどの画面にも入れておらず、戻れる祖先がない。
