# `auth` 外枠（画面要件）

> 機能要件は持ちません。この外枠が約束するのは見え方だけです。

認証の往復に関わる画面を包むレイアウトシェル。

- [`/login`](login/page.screen.ja.md)
- [`/onboarding`](onboarding/page.screen.ja.md) <!-- sample:line -->

## 見せるもの

他の画面を包むレイアウトシェルとは分けたレイアウトシェルで、**ナビゲーションもサイドバーも出さない**。認証を促している最中に
他の導線を並べると、そこから離脱した利用者が元の操作へ戻れなくなる
（[0026](../../../adr/0026-layout-shell-mount.ja.md)）。

**それでもレイアウトシェルそのものは通す。** header の site 名からトップ（`/`）へ戻れる経路を残すためで、枠ごと
外すと認証をやめたい利用者に「戻る」以外の手段が無くなる。

## パンくず

置かない。このレイアウトシェルの中の画面に着いた利用者はまだどの画面にも入れておらず、戻れる祖先がない。
