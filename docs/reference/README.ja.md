# リファレンス

**コードに追随して変わるインベントリ**を置く。ここにある文書は ADR ではない —— 何かを決めた記録では
なく、いま `package.json` や設定ファイルに何が在るかを、人が読める単位に束ね直した**生きた
参照**である。コードが動けば同じ変更の中で書き換わり、書き換わらなければ古くなる。

[`docs/README.md`](../README.ja.md) の 4 分類でいう **inventory** の家がここである。decision /
exclusion（[`adr/`](../adr/)）・rule（[`rules.md`](../rules.ja.md)）は根拠を持つが、インベントリは根拠を
持たない。**「なぜこれを選んだか」はここに書かない** —— 書けばインベントリが根拠の顔をしたまま腐る。
選定の判断は ADR が持ち、インベントリはそこへリンクするだけである。

## 契約

| | ここ（インベントリ） | ADR |
| --- | --- | --- |
| 何に追随するか | **コード**（`package.json` など）、または**解釈の元にした原典** | 何にも追随しない。決定そのもの |
| いつ変わるか | 対象が変わるたび、**同じ変更の中で** | 別の案を選び直したときだけ |
| 何を答えるか | 何が在り、何を担っているか | 何を選び、何を却下したか |
| 正はどちらか | **コード側**。ここは束ね直したコピー | ADR 本文 |

インベントリの行を足す・消す・書き換える理由は、コード側にその変化が起きたことだけである。インベントリを先に
書いてコードを後から合わせることはしない。
